# Projeto: Aplicativo Móvel para Agendamento de Consultas Médicas

## Descrição do Projeto
Este projeto consiste na estruturação e gestão de riscos para o desenvolvimento de um aplicativo móvel de agendamento de consultas médicas, integrando cadastro de usuários, gestão de agenda, notificações e prontuário médico externo.

## Objetivo do Exercício
Realizar a identificação, análise e planejamento de respostas a riscos, além da elaboração de uma comunicação estratégica para stakeholders utilizando Inteligência Artificial Generativa.

## Estrutura do Repositório
- `README.md`: Apresentação geral do projeto e objetivo.
- `riscos/`: Pasta contendo a gestão de riscos do projeto.
  - `identificacao.md`: Identificação dos riscos potenciais.
  - `analise.md`: Análise qualitativa dos riscos (impacto e probabilidade).
  - `respostas.md`: Estratégias e planos de ação para os riscos.
- `comunicacao/`: Pasta contendo o alinhamento com stakeholders.
  - `status-stakeholders.md`: Relatório e comunicação de status do projeto.
