# Estratégias de Resposta aos Riscos

## Risco 1: Instabilidade na API Externa
- **Estratégia:** Mitigar / Transferir
- **Justificativa:** Reduzir a dependência imediata do sistema externo para não travar o desenvolvimento.
- **Ações:** Criar uma camada de integração simulada (Mock Server) e agendar reuniões técnicas de alinhamento com os responsáveis pelo sistema externo.

## Risco 2: Mudança de Requisitos
- **Estratégia:** Mitigar
- **Justificativa:** Controlar a entrada de novos requisitos sem impedir a evolução do projeto.
- **Ações:** Formalizar um fluxo de aprovação de mudanças (Change Request) e redefinir o escopo da versão atual (MVP).

## Risco 3: Sobrecarga da Equipe
- **Estratégia:** Mitigar / Aceitar
- **Justificativa:** Ajustar a capacidade real de entrega para evitar burnout e bugs em produção.
- **Ações:** Repriorizar tarefas no backlog, focar nas funcionalidades críticas e reavaliar os prazos de entrega junto aos stakeholders.
